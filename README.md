# xoxo-gossip-giRL
My goal with this project is to create and train a Reinforcement Learning Model from scratch that is able to play the simple game "Xs and Os" (which you may know by the name "Tic-Tac-Toe" or "Noughts and Crosses").

If you would like to learn more about the qmap greedy epsilon approach to machine learning used in this project I would highly recommend ["Artificial Intelligence: A Guide for Thinking Humans"](https://melaniemitchell.me/aibook/) by Melanie Mitchell which I based almost all of this project on.
