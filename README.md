# xoxo_gossip_giRL
My goal with this project is to create and train a Reinforcement Learning Model from scratch that is able to play the simple game "Xs and Os" (which you may know by the name "Tic-Tac-Toe" or "Noughts and Crosses").
I did this to reinforce (har har har) my own understanding of these concepts as precursor to more ambitious projects in the future.

If you ain't got no money your broke-ass can stay right where it is as a matter of fact, because this code should run fine on a regular laptop.

If you would like to learn more about the Q-map epsilon-greedy approach to Reinforcement Learning used in this project I would highly recommend ["Artificial Intelligence: A Guide for Thinking Humans"](https://melaniemitchell.me/aibook/) by Melanie Mitchell which is where I lifted basically all of this from.
